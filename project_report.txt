# Time Series Forecasting Using LSTM, MC Dropout and SARIMA

## Abstract

This project presents a comparative framework for time series forecasting using deep learning and classical statistical models. A standard LSTM network is implemented for point prediction, while an MC Dropout-based LSTM is used to estimate predictive uncertainty. Additionally, a SARIMA model is integrated as a baseline. The system is evaluated using quantitative metrics such as RMSE, MAE, prediction interval coverage, and interval width.

## 1. Introduction

Time series forecasting plays a critical role in finance, weather prediction, and demand planning. Traditional statistical models often struggle with nonlinear patterns, motivating the use of deep learning approaches. This project explores the effectiveness of LSTM networks along with uncertainty estimation using MC Dropout and compares them with a SARIMA baseline.

## 2. Objectives

• Generate synthetic time series data
• Preprocess data for sequential modeling
• Train LSTM and MC Dropout LSTM models
• Implement SARIMA baseline
• Evaluate models quantitatively
• Visualize predictions with uncertainty

## 3. Dataset Description

A synthetic dataset based on a sine wave pattern is generated. It consists of sequential numerical values stored in a column named "value". The controlled nature of the dataset allows effective performance comparison.

## 4. Data Preprocessing

The dataset is converted into supervised learning format using a sliding window approach with a sequence length of 10. The dataset is split into 80% training and 20% testing sets and reshaped for LSTM input.

## 5. Models Used

### LSTM Model

A neural network with one LSTM layer followed by a dense output layer optimized using Adam and MSE loss.

### MC Dropout LSTM

An LSTM model with dropout layers active during inference to generate uncertainty estimates.

### SARIMA Model

A classical time series model with seasonal order aligned to the synthetic data periodicity.

## 6. Evaluation Metrics

• Root Mean Squared Error (RMSE)
• Mean Absolute Error (MAE)
• Prediction Interval Coverage
• Average Interval Width

Confidence intervals are calculated using Mean ± 1.96 × Standard Deviation assuming approximate Gaussian distribution.

## 8. Discussion

LSTM networks effectively capture nonlinear temporal patterns. The SARIMA model serves as a useful baseline but is less accurate for complex data. Uncertainty estimation improves interpretability and decision reliability.

## 9. Conclusion

The project demonstrates the superiority of LSTM-based models for time series forecasting and highlights the importance of uncertainty quantification using MC Dropout.
